# Exchangel

A currency and cryptocurrency converter for Telegram Mini Apps, hosted on
Telegram Serverless.

[Open the app](https://app6547657300.tgcloud.ai/)

- Fiat and crypto conversion with a built-in calculator.
- Custom currency lists and search by asset type.
- English and Russian interfaces.

Fiat rates come from ExchangeRate-API; cryptocurrency rates and icons come from OKX.
The frontend uses plain JavaScript and CSS.

## Development

```sh
cd exchangel_bot
npm ci
npm run dev
```

See the [project documentation](exchangel_bot/README.md) for testing, deployment,
and architecture.
